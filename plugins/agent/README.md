# agent

Skills for how agents work in a project.

## Skills

### managing-agent-instructions

Sets up and maintains the project-level agent instructions file (`CLAUDE.md`, `AGENTS.md`): glossary, "read when" map, commands, and a workflow table routing each step to the skill or tool to use first.

See [`skills/managing-agent-instructions/SKILL.md`](./skills/managing-agent-instructions/SKILL.md).

## Installation
