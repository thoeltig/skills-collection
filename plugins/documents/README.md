# documents

Skills for creating and maintaining project documentation.

## Skills

### managing-changelog

Creates, updates, and maintains CHANGELOG.md files following Common Changelog and Keep a Changelog standards.

See [`skills/managing-changelog/SKILL.md`](./skills/managing-changelog/SKILL.md).

### managing-documentation

Creates, updates, and maintains project documentation following best practices for clarity, accessibility, and inclusivity.

See [`skills/managing-documentation/SKILL.md`](./skills/managing-documentation/SKILL.md).

## Installation

```
/plugin install documents@skills-collection
```
